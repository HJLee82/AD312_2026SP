# TaskManager with React State

A React task manager app that demonstrates how to update arrays and objects in React state using the spread syntax and map() method.

## Features
- Add new tasks with a title
- Mark tasks as completed or undo completion
- Delete tasks
- Completed tasks move to the bottom with strikethrough
- Press Enter to quickly add a task

## Tech Stack
- React + Vite
- useState hook with spread operator and map() for immutable state updates

## How to Run

1. Clone the repository

2. Install dependencies
   npm install

3. Start the dev server
   npm run dev

4. Open http://localhost:5173 in your browser
