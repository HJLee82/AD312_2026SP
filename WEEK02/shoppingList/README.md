# Shopping List with Immer

A React shopping list app that uses the `useImmer` hook to manage complex nested state.

## Features
- Browse 4 stores: Costco, Trader Joe's, Safeway, and Hmart
- Each store has its own independent shopping list
- Add, update, and delete items
- Mark items as bought (moves to bottom with strikethrough)
- Each item stores nested details: category and notes

## Tech Stack
- React + Vite
- [use-immer](https://github.com/immerjs/use-immer) for state management
