# Managing Nested State in React

A React app that demonstrates how to update nested state objects immutably using the spread operator and useState hook.

## Features
- View a user profile with nested address information
- Update street, city, and country fields
- Real-time display of current profile state
- Undo and redo address changes

## Tech Stack
- React + Vite
- useState hook with spread operator

## How to Run

1. Clone the repository

2. Install dependencies
   npm install

3. Start the dev server
   npm run dev

4. Open http://localhost:5173 in your browser
