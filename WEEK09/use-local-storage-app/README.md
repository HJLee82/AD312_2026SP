# Custom Hook for localStorage Sync - useLocalStorage

A custom hook that works like useState but automatically saves and loads values from localStorage, demonstrated with a global Dark Mode switcher.

## Features
- useLocalStorage hook syncs state with localStorage automatically
- Theme preference persists across page refreshes
- Safe error handling for corrupted localStorage values

## How to Run
```bash
npm install
npm run dev
```

## Tech Stack
- React + Vite
