# Error Boundary App - Application Safety Net in React

A social media dashboard demonstrating React Error Boundaries to isolate component crashes and display fallback UI.

## Features
- Error Boundary using Class Component with getDerivedStateFromError
- Crashing widget is isolated — rest of the app stays functional
- Fallback UI displayed instead of blank screen
- Reset functionality to recover from errors

## How to Run
```bash
npm install
npm run dev
```

## Tech Stack
- React + Vite
