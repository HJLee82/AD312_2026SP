# User Registration Form with React Hook Form

A client-side validated user registration form built with React + Vite + React Hook Form.

## Features
- 6 form fields with validation: Full Name, Email, Password, Confirm Password, Role, Terms
- No useState for form fields — powered by React Hook Form
- Auto-focus on Full Name field on mount
- localStorage draft caching with watch + useEffect
- Loading state on submit button
- 2-second simulated API delay with form reset on success

## How to Run
```bash
npm install
npm run dev
```

## Tech Stack
- React + Vite
- React Hook Form
