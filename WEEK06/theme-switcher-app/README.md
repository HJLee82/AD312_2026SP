# Theme Switcher App - Global Dark Mode with React Context

A React app that implements a global Light/Dark mode switcher using the React Context API.

## Features
- Global theme state managed with React Context
- Toggle between light and dark mode with a single button
- Dynamic CSS classes applied based on current theme
- Handles missing ThemeContext gracefully

## How to Run
```bash
npm install
npm run dev
```

## Tech Stack
- React + Vite
- React Context API
