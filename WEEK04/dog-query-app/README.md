# Dog Query App

A React application that fetches and displays dog breed information using TanStack Query.

## Features
- Browse a list of dog breeds
- View detailed information for each breed
- Random dog facts that update on every breed selection
- Dog group information
- Handles loading, error, and success states

## Tech Stack
- React (Vite)
- TanStack Query

## How to Run
```bash
npm install
npm run dev
```

## API
[Dog API](https://dogapi.dog/)
