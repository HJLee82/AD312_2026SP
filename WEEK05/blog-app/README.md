# Blog App - Multi-Page Layout with React Router

A multi-page blog application built with React + Vite + React Router DOM.

## Features
- Home feed with list of blog posts
- Individual post detail pages (dynamic routing)
- About page
- 404 page for unknown routes

## How to Run
```bash
npm install
npm run dev
```

## Routes
- `/` → Home (post list)
- `/about` → About page
- `/post/:id` → Individual post detail
- `*` → 404 Not Found

## Tech Stack
- React + Vite
- React Router DOM
