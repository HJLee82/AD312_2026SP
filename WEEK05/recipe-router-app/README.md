# Recipe Router App - Multi-Page Recipe Gallery with React Router

A multi-page recipe gallery application built with React + Vite + React Router DOM.

## Features
- Home welcome page
- Recipe gallery with all recipes displayed
- Individual recipe detail pages (dynamic routing)
- 404 page for unknown routes

## How to Run
```bash
npm install
npm run dev
```

## Routes
- `/` → Home
- `/gallery` → Recipe Gallery
- `/recipe/:id` → Individual Recipe Detail
- `*` → 404 Not Found

## Tech Stack
- React + Vite
- React Router DOM
