# Chart.js Poll Dashboard - Bridging React with Non-React Libraries

A dynamic poll dashboard built by integrating the Chart.js library into a React component using useEffect.

## Features
- Real-time bar chart updates on vote
- Chart instance managed with useRef
- Cleanup function prevents memory leaks
- Reset votes functionality

## How to Run
```bash
npm install
npm run dev
```

## Tech Stack
- React + Vite
- Chart.js
